# React Azure Blob Upload Sample

Small sample app that uploads files from React to Azure Blob Storage with:

- Drag-and-drop or file browsing UI via Uppy Dashboard
- Default destination container: `uploads`
- No storage account keys in frontend code
- Short-lived User Delegation SAS generated by backend
- Large-file resilience through Uppy retry behavior and Golden Retriever recovery

## Project Structure

- `frontend`: React + Vite + Uppy uploader
- `backend`: Node + Express API for SAS token issuance

## Prerequisites

- Node.js 20+
- Azure Storage account
- Azure identity with role `Storage Blob Data Contributor` on the storage account

## Azure Setup

1. Create or use an existing StorageV2 account.
2. Create a private container named `uploads` (or let backend auto-create it).
3. Grant your backend identity `Storage Blob Data Contributor`.
4. For local development, run `az login` so `DefaultAzureCredential` can obtain a token.

## Configure Environment

1. Backend env:

```bash
cp backend/.env.example backend/.env
```

Set `AZURE_STORAGE_ACCOUNT_NAME` to your storage account name.

2. Frontend env:

```bash
cp frontend/.env.example frontend/.env
```

## Run Locally

Terminal 1:

```bash
cd backend
source "$HOME/.nvm/nvm.sh"
npm run dev
```

Terminal 2:

```bash
cd frontend
source "$HOME/.nvm/nvm.sh"
npm run dev
```

Open the app at `http://localhost:5173`.

## API Contract

### `POST /api/upload/sas`

Request body:

```json
{
  "fileName": "my-file.zip",
  "fileSize": 104857600,
  "contentType": "application/zip"
}
```

Response:

```json
{
  "uploadUrl": "https://<account>.blob.core.windows.net/uploads/<blob>?<sas>",
  "blobName": "2026-...-uuid-my-file.zip",
  "containerName": "uploads",
  "expiresOn": "2026-06-08T00:00:00.000Z"
}
```

## Security Notes

- Storage account keys are never sent to the client.
- SAS tokens are scoped to one blob with create/write and short expiration.
- API includes basic rate limiting and CORS origin restriction.
